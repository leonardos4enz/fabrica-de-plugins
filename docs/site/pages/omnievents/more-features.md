# More features

Once you are comfortable with [triggers](triggers.md), [conditions](conditions.md) and [actions](actions.md), these
features take your rules further.

| Feature | In one line |
|---|---|
| [State rules](features/state-rules.md) | "When X **becomes** true" with `on_enter` and `on_exit`, without polling. |
| [Rule tests](features/rule-tests.md) | Test cases inside your YAML that run on every reload, with no real effects. |
| [Menus](features/menus.md) | Inventory menus where each click is a small rule, and native forms for Bedrock players. |
| [Packs and templates](features/packs-and-templates.md) | Share a folder of rules without name clashes, and reuse rules with `${parameters}`. |
| [Integrations](features/integrations.md) | Vault money, WorldGuard regions, Citizens NPCs, ProtocolLib and PlaceholderAPI. |
| [Performance](features/performance.md) | Measure what each rule costs with `/omni cpu`, and set a time `budget`. |
| [Java API](features/java-api.md) | Add your own functions, actions and properties from another plugin. |

The full explanation of each feature is in the
[plugin README](https://github.com/leonardos4enz/fabrica-de-plugins/blob/main/plugins/omnievents/README.md) (in
Spanish); these pages are the English summary.
