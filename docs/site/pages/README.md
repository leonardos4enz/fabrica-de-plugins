# Plugin Factory Docs

Documentation for the Paper plugins built in the
[plugin factory](https://github.com/leonardos4enz/fabrica-de-plugins) repository.

| Plugin | What it does | Start here |
|---|---|---|
| **OmniEvents** | "When X happens, if Y is true, do Z", written in YAML. A rule engine for Paper servers with a real expression language, persistent variables, menus and rule tests. | [Overview](omnievents/README.md) |

New to OmniEvents? Read [Installation](omnievents/installation.md), then [Your first rule](omnievents/first-rule.md).
Coming from ConditionalEvents? Go to [Migrating from ConditionalEvents](omnievents/migrating-from-conditionalevents.md).

> The plugins are developed in Spanish: the repository, the in-game messages and the generated reference are in
> Spanish. These pages are the English documentation.
